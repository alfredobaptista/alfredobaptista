## 🚀 Projectos em Destaque

### 💳 Resilient Payment Gateway

**Java 21 · Spring Boot 3 · PostgreSQL · Redis · Resilience4j · OpenFeign · Docker**

<a href="https://github.com/alfredobaptista/resilient-payment-gateway">
  github.com/alfredobaptista/resilient-payment-gateway
</a>

Gateway de pagamentos desenvolvido com foco em **resiliência, consistência e prevenção de transacções duplicadas**.

Principais aspectos técnicos:

* Implementação de **idempotência utilizando Redis**
* Protecção contra transacções duplicadas em cenários concorrentes
* **Circuit Breaker** para isolamento de falhas
* **Retry** para recuperação automática de falhas transitórias
* Integração entre serviços utilizando **OpenFeign**
* Arquitectura orientada à separação de responsabilidades
